## 🔹 Sobre o Projeto
**Neon Escape** é um **3D Infinite Runner** com estilo **low poly**, desenvolvido como projeto para uma prova da faculdade.  
O objetivo do jogo é coletar **cristais** antes do tempo acabar, usando **gestos de swipe** para pular e se mover lateralmente.

## 🔹 Recursos Utilizados
- **Skybox:** Procedural Skybox 2.0 Lite  
- **Modelos 3D:**  
  - SimplePoly City – Low Poly Assets  
  - PolyKebap  
  - Personagem do Mixamo (Mousey)  
- **UI e Texto:** TextMeshPro
- - **Musica:** OpenGameArt: Cyberpunk Moonlight Sonata

## 🔹 Mecânicas de Jogo
- Jogador se move para **esquerda, direita** ou **pula** usando gestos de swipe.  
- Colete **cristais** antes que o tempo acabe.  
- Infinite Runner com dificuldade crescente à medida que o jogador avança.

## 🔹 Estrutura do Projeto
O projeto inclui todos os arquivos necessários para abrir e editar no Unity:  
- Pasta `Assets`  
- Pasta `ProjectSettings`  
- Pasta `Packages`  
- Outros arquivos do projeto  

> **Nota:** Inclua o `.gitignore` para ignorar pastas temporárias, builds e arquivos do sistema.

## 🔹 Como Rodar
1. Faça o download do projeto pelo GitHub ou Google Drive.  
2. Abra o projeto no **Unity Hub** (recomenda-se versão: Unity 6.2 (6000.2.4.f1)).  
3. Abra a cena principal `MainScene.unity`.  
4. Clique em **Play** para testar no editor ou faça build para mobile.
